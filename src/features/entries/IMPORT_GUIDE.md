# Day Sheet Import Feature

## Overview
The Day Sheet Import feature allows you to import procedure entries from PDF reports generated by your dental practice management software.

## Supported Formats
- **Day Sheet (Alphabetical)** PDF reports
- CSV files (manual conversion)

## How to Use

### Step 1: Navigate to Entries
1. Go to the **Entries** page
2. Make sure you're on the **Performance** tab

### Step 2: Import Report
1. Click the **Import Report** button (green button in toolbar)
2. Select the practice you want to import entries for
3. Upload your Day Sheet PDF file

### Step 3: Review and Confirm
1. The system will automatically:
   - Parse the PDF
   - Combine multiple procedures for the same patient on the same day
   - Calculate totals
2. Review the preview table showing:
   - Patient names
   - Dates
   - Combined procedure codes
   - Production and collection amounts
3. You can:
   - Edit any field by clicking on it
   - Remove entries you don't want to import (trash icon)
   - Restore removed entries (checkmark icon)

### Step 4: Import
1. Click **Import X Entries** to add them to your database
2. The entries will appear in your Entries list

## Data Aggregation

When importing, the system automatically combines multiple procedures for the same patient on the same date into a single entry:

**Example:**
If the report shows:
```
03/26/2026 Barrios, Dennis  15  D2391  Resin-based comp  55.00  0.00
03/26/2026 Barrios, Dennis  18  D2391  Resin-based comp  55.00  0.00
03/26/2026 Barrios, Dennis  18  D2999.3  Premium Material  103.00  0.00
```

It will be imported as a single entry:
- **Patient:** Barrios, Dennis
- **Date:** 2026-03-26
- **Procedures:** D2391, D2391, D2999.3
- **Production:** $213.00
- **Collection:** $0.00
- **Notes:** 15-D2391 (Resin-based comp); 18-D2391 (Resin-based comp); 18-D2999.3 (Premium Material)

## CSV Alternative

If PDF parsing fails, you can manually convert your report to CSV format:

### CSV Format
```csv
Date,Patient Name,Tooth,Code,Description,Surface,Charges,Payments
2026-03-26,Barrios Dennis,15,D2391,Resin-based comp-1s posterio,O,55.00,0.00
2026-03-26,Barrios Dennis,18,D2391,Resin-based comp-1s posterio,O,55.00,0.00
```

### CSV Requirements
- **Header row required** (shown above)
- **Date format:** YYYY-MM-DD
- **Patient name:** Can be "LastName, FirstName" or "LastName FirstName"
- **Numeric values:** Use decimal notation (e.g., 55.00, not $55.00)

## Troubleshooting

### PDF Not Parsing Correctly
1. Ensure the PDF is a Day Sheet (Alphabetical) report
2. Check that the PDF contains readable text (not scanned images)
3. Try exporting the report again from your practice management software

### Missing Procedures
1. Check if the procedure has $0.00 charges - these are still imported
2. Verify the date range if using filters
3. Look in the notes field for combined procedure details

### Incorrect Totals
1. Review the preview before importing
2. Edit any incorrect values in the confirmation modal
3. Remove and re-import if needed

## Tips

- **Backup first:** Export your current entries before large imports
- **Test with small files:** Start with a single-day report to verify formatting
- **Review carefully:** Always check the preview before confirming import
- **Use filters:** After import, use date filters to review new entries
